# Scoop bucket for SourceOrrery

The `sourceorrery` CLI for Windows, x64 and arm64. The manifest downloads
the archive attached to a
[GitHub release](https://github.com/Netizine/sourceorrery/releases) and
checks its SHA-256 against the one recorded at release time.

```powershell
scoop bucket add sourceorrery https://github.com/Netizine/scoop-sourceorrery
scoop install sourceorrery
sourceorrery --help
```

`bucket/sourceorrery.json` is generated by the release workflow of
[Netizine/sourceorrery](https://github.com/Netizine/sourceorrery)
(`scripts/release/package-managers.py`) and committed here on every
release. Edit it there, not here. Documentation: <https://sourceorrery.ai>.
